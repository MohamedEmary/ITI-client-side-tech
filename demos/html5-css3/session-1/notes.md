# HTML5

## History of HTML

- HTML5 -> HTML, CSS3, JS
- W3C
- HTML2 -> HTML3 -> HTML4 -> XHTML -> HTML5
- XML (Extensible Markup Language)
  - Extensible because you can create your own tags
  - Any attribute must have a value
- `disabled` `readonly` `checked` `selected` `multiple` `required`: defaults to true
- WHATWG (Web Hypertext Application Technology Working Group)
- 2004 W3C
- HTML5 2014 W3C Recommendation

---

## What is new?

### HTML

- New Tags and input types
- New semantic tags
  - `<header>` `<footer>` `<nav>` `<article>` `<section>` `<aside>` `<main>`
- Audio and Video
  - `<audio>` `<video>`
- Canvas (2D and 3D graphics) (Phaser.js for games)
  - `<canvas>`

### CSS

- JQuery `animate()`
- animation and keyframes
- New selectors

### JS

- HTTP is a **stateless protocol** (Cookies)
- `localStorage` and `sessionStorage`
- Worker API (Web Workers)
  - Notifications
- Geolocation API
